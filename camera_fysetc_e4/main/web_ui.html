Motor calibration

×

IRUN CS is run current (3-16). I_rms ~ (CS+1)/32 * 0.325 / (0.11 * 1.414). Defaults: pan/tilt 11 (~0.78 A), zoom 5 (~0.39 A). Lower zoom if the rubber ring clicks; raise it if mid-range stalls. Lower pan/tilt if a hard stop grinds; raise if the axis loses steps under load. Apply writes the driver and saves it.

Motor debug (TMC)

×

Probe checks UART1 (GPIO22/21). The E4 only ties those pins to the TMC PDN bus when two shunts sit on the I2C/USART1 column (P17) to the center TMC column (P18), not on the USB TX/RX column. IC version 0x21 = TMC2209, write_ack means IFCNT incremented so the driver actually heard a write. GCONF/CHOPCONF/version are read from the chip. IHOLD/IRUN/SGTHRS/TCOOLTHRS are write-only on TMC2209 (a read is always 0); the probe shows the values last written. Change run current in Motor calibration.
